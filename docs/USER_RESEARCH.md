# Reach and user research

**No interviews or country reach are claimed yet.** Reach requires real people, not generated testimonials.

Use this five-minute study with participants in at least three countries:

1. What would make you hesitate to let an AI assistant read a private document?
2. Without explanation, ask them to create the expense report and review its permission request.
3. Can they tell which documents the agent can read and when that access ends?
4. When payroll access is denied, do they understand that the expense task can continue?
5. Can they verify the receipt and explain what it proves?
6. Would they use this for a real task? What would need to change first?
